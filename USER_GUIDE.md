# Web-Based Academic Repository - User Guide

## Getting Started

### 1. Account Access
- **Login**: Use your credentials to access the system at the login page
- **Dashboard**: After login, you'll be directed to your personal dashboard

## Main Features

### 2. Upload Documents
1. Navigate to the **Upload** page from the menu
2. Click "Choose File" and select your document (PDF, DOCX, TXT)
3. Fill in the required metadata:
   - Title
   - Author(s)
   - Category
   - Abstract (optional)
4. Click **Upload** to submit your document
5. The system will automatically check for plagiarism

### 3. Quick Scan
1. Go to the **Quick Scan** page
2. Paste or type your text directly into the text box
3. Click **Scan** to check for plagiarism
4. View instant results showing similarity percentage and matches

### 4. My Documents
1. Access **My Documents** to view all your uploaded files
2. Features available:
   - View document details
   - Check plagiarism status
   - Download documents
   - Delete documents

### 5. Browse Repository
1. Use the **Dashboard** to browse available documents
2. Filter by category, date, or search by keywords
3. View document details and download public documents

## Understanding Results

### Plagiarism Report
- **Similarity Score**: Percentage showing how much content matches existing sources
- **Matched Sources**: List of documents or websites with similar content
- **Highlighted Text**: Color-coded sections showing matched content

## Administrator Features (Admin Only)

- **User Management**: Add, edit, or remove users
- **Document Approval**: Review and approve uploaded documents
- **System Reports**: View usage statistics and plagiarism trends
- **Settings**: Configure system parameters

## Tips for Best Results

1. **Document Format**: Use clear, well-formatted documents
2. **Metadata**: Provide accurate information for better categorization
3. **File Size**: Keep documents under the maximum allowed size
4. **Citations**: Properly cite sources in your documents

## Need Help?

- Check the **About** page for more information
- Contact system administrator for technical issues
- Review your document submission before finalizing
