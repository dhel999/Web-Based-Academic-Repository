AcadRepo

System Overview

Academic repository and integrity management system

AcadRepo is a web-based academic repository designed to store, organize, manage, and preserve students’ thesis, research papers, capstone projects, and other academic documentation. The system provides a centralized platform where students can securely submit their academic documents, while authorized administrators and advisers can review, manage, and monitor submitted research.

It includes document metadata, search and filtering, document archiving, and similarity detection using TF-IDF and cosine similarity to identify potential similarities between newly submitted documents and previously stored academic works. The system can also maintain detection results so that the same document does not need to be analyzed repeatedly, helping reduce unnecessary API or AI usage.

Through AcadRepo, academic documents can be systematically preserved and made easier to search, review, and reference, while maintaining appropriate access and privacy controls for student research.

Document Storage

Stores thesis, research papers, and academic projects in a central repository for long-term access and organization.

Similarity Analysis

Checks documents with TF-IDF and cosine similarity to detect overlapping content and possible duplication.

Access Control

Provides controlled access for students, advisers, and administrators while preserving privacy and authorization.
